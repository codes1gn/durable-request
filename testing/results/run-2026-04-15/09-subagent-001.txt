REST centers on resources identified by URLs manipulated with HTTP verbs. GraphQL centers on a typed schema and a single endpoint where the client specifies the shape of data required.

Key tradeoffs:
- Over/under-fetching: REST can under-fetch or over-fetch; GraphQL reduces shape mismatch
- Caching: HTTP caching maps naturally to REST URLs; GraphQL needs different strategies
- Evolution: REST uses URL versioning; GraphQL uses schema deprecations and field analytics
